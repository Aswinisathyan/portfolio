Portfolio Website is a modern personal portfolio designed to showcase my skills, projects, and achievements. It provides a clean, professional interface for recruiters and visitors to explore my profile, view my work, and contact me easily.

---

## Features
- **Responsive Design:** Works smoothly on mobile, tablet, and desktop screens.
- **Modern UI:** Clean layout with a professional theme and smooth visuals.
- **Animated Sections:** Uses Framer Motion animations for an engaging user experience.
- **Projects Showcase:** Displays my projects with descriptions and key details.
- **Skills & Education Section:** Highlights my technical skills, academic background, and strengths.
- **Resume Download:** Allows visitors to download my resume directly.
- **Contact Section:** Provides easy access to contact details and social profiles.

---

## How It Works
1. Visitors open the portfolio website.
2. The homepage introduces my profile and key highlights.
3. Users can scroll through sections like About, Skills, Education, and Projects.
4. Resume can be downloaded through the Resume button.
5. Visitors can contact me using the Contact section or social links.

---

## Technologies Used
- React (Vite)
- Tailwind CSS
- Framer Motion (for animations)
- Lucide React (icons)
- GitHub Pages (deployment / hosting)

---

## Benefits
- Provides a professional online presence.
- Helps recruiters quickly view projects and skills.
- Easy to update and redeploy anytime.
- Fast loading and optimized performance using Vite.
